PACE 校園運動
運動模板教學講義

用手機，把校園走成一張地圖。

Android 與 iPhone 的使用形式

本模板是可加入主畫面的響應式網頁（PWA），不是 APK 或 App Store 原生 App。同一份 HTTPS 網址可在 Android Chrome 與 iPhone Safari 開啟，不必另外開發兩套介面。

AndroidiPhone
用 Chrome 開啟 HTTPS 網址 → 允許位置與精確定位 → 瀏覽器選單中使用「加到主畫面」或「安裝」（名稱依版本而異）。用 Safari 開啟 HTTPS 網址 → 允許位置與精確定位 → 分享選單 →「加入主畫面」（名稱依版本而異）。

安裝選項依瀏覽器及系統版本而異，即使沒有安裝按鈕也可以直接用網頁。首次開啟需連網；介面可快取，但校園底圖與外部導航仍需網路。

學生操作流程

  1. 按「開始運動」，在設定視窗輸入課堂代號、身高、體重與年齡；活動強度會依 GPS 移動速度自動判斷。熱量、距離、時間目標可各自勾選與設定；全部關閉就是自由運動。
  2. 閱讀並勾選資料記錄同意；按「開始 GPS 運動」。若只是測試，按「先體驗示範運動」。
  3. 在戶外等待第一個精度合格的定位點；成功後才開始計時。
  4. 點地圖設定老師指定集合點。虛線是直線方向；「步行導航」開啟 Google Maps。
  5. 運動達成目標後不會自動停止，仍可繼續運動；按下結束才會儲存。運動開始後會進入專注畫面並嘗試保持螢幕亮著；請讓網站留在前景，切換 App、外部導航或鎖屏可能觸發自動暫停。返回後按「繼續」，休息時手動暫停。iPhone Safari 分頁會保留瀏覽器介面；加入主畫面並從圖示開啟，才會以獨立視窗呈現。螢幕常亮需 iOS 18.4 以上的主畫面網頁 App 支援。
  6. 結束並儲存。從歷程匯出 CSV 摘要或 JSON 軌跡，可刪除單筆或全部紀錄。

教師部署：讓全班可用

Sites 預設發佈為擁有者私有，私人預覽網址不等於學生可直接使用的班級網址。正式上課可將完整全端專案部署至支援 Worker、D1 與平台登入的環境，或在 Sites 管理介面設定符合學校政策的分享對象，並以學生帳號驗證權限。

  1. 班級資料庫需要後端服務；只上傳 public 靜態檔案可使用本機運動介面，但無法使用雲端班級功能。
  2. 確保網站使用 HTTPS，且沒有禁止 geolocation 的 Permissions-Policy；不要直接用手機開啟本機 HTML 或 HTTP 區網網址。
  3. 先用一台 Android 與一台 iPhone 測試允許／拒絕定位、走 100–200 公尺、暫停繼續、切換背景與匯出。
  4. 老師現場確認安全區域、開放校門、集合點與雨天替代方案；再分享網址或製作 QR code。

課前實測清單

  • 學生無需擁有者帳號即可進入指定分享範圍。
  • 拒絕定位時顯示說明，不會產生假 GPS 軌跡。
  • 示範紀錄明確標示，不能當成真實出席證明。
  • 同一路線兩次量測的差異可接受，確認不會穿越禁止通行區域。
  • 匯出的 CSV 能在教師使用的試算表開啟。

班級資料庫

請至 班級中心 加入或建立班級。學生在運動歷程按「繳交」，確認後提交摘要；詳細設計見 資料庫說明。

目前範圍與擴充方向

目前所有人都使用 GPS 記錄位置、移動速度與估算熱量，並可設定熱量、距離和時間目標，或不設目標自由運動；網站不連接 Apple Watch，也不記錄心率。首頁的「本月任務」依本機已完成的 GPS 紀錄更新五項固定目標：5 km、15 km、500 kcal、1,500 kcal 與運動 5 天；每天至少完成 10 分鐘 GPS 運動才計為一個運動日。每月也可新增最多 10 項個人任務，自訂距離、熱量或運動天數目標，並選入門、進階或挑戰難度。任務與進度只儲存在這台裝置，不會建立好友排行榜或傳送到雲端；換月份時個人任務會重新開始。運動歷程也可展開每筆 GPS 紀錄的地形高度折線圖與爬升／下降估算；按下按鈕時，最多 100 個抽樣路線座標會送至 Open-Meteo，使用全球 Copernicus DEM GLO-90 地形資料（約 90 公尺解析度），未點選時不會傳送。Open-Meteo 可能記錄 API 請求資訊，詳見使用條款。高度圖僅供路線起伏參考，不能代替實測氣壓高度計。完整軌跡只在此裝置；v3 新增班級中心、教師審核與手動提交摘要。沒有自動上傳或防作弊機制。

若日後要長時間鎖屏持續記錄，需另行開發具原生背景定位權限的 Android／iOS App，並實機驗證耗電、權限與商店政策；只把網頁包裝成 App 不會自動解決背景定位。
